# Contributing

`main` is protected: every change except the repository owner's must arrive through a pull request, and direct pushes are rejected.

## Workflow

1. Open an issue first for bug reports, feature requests, or behavior changes.
2. Fork the repository and work on a branch.
3. Open a pull request against `main`, describing the motivation and how you verified the change.
4. Keep `npm test` green (`npm test` needs Node.js 24; PTY tests also need Python 3).

## 贡献指南

`main` 已启用分支保护：除仓库所有者外，所有改动都必须通过 Pull Request，直接推送会被拒绝。

1. 反馈缺陷、需求或行为变更，请先在 Issues 中开 issue。
2. Fork 仓库，在独立分支上开发。
3. 向 `main` 提交 Pull Request，说明改动动机与验证方式。
4. 保持 `npm test` 通过（需要 Node.js 24，PTY 测试另需 Python 3）。
